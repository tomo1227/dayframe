# Dayframe

Plan your day. Frame your life.

Markdownで一日を計画し、タイムラインで確認し、ストーリーズ用の画像として残すiPhone / Macアプリです。Swift 6.4、SwiftUI、SwiftData、CoreText、ImageIOのみを使用します。第三者フレームワークや独自ログインはありません。

## 起動

Xcode 27.2以降、iOS / macOS 27以降が必要です。

- `Dayframe.xcodeproj`を開き、`Dayframe`スキームとMacまたはiPhone Simulatorを選んで実行します。
- Macのローカル版は`make run`で起動できます。アプリは`.build/Dayframe.app`に生成されます。
- 実機ではSigning & Capabilitiesで自分のTeamと、一意のBundle Identifierを設定してください。
- 日付一覧から過去・未来へ移動できます。MacはMarkdownとプランを左右分割、狭いウィンドウとiPhoneは切り替え表示です。
- カレンダーの日付をタップすると、その日のプランを開きます。iPhoneでは選択済みの日付も開き直せます。年月をタップして日付ピッカーを回しても、表示する月が変わるだけです。年月をもう一度タップするとカレンダーに戻ります。「日々のプラン」には内容のある日だけが表示され、日付を開くだけでは保存されません。
- ツールバーの追加ボタンでタスク作成、各タスクのメニューで編集・削除・同一セクション内の並び替えができます。セクションの追加・名前変更、Markdownの入出力はプランの操作メニューから行います。
- タスクの追加・編集で「時刻を設定」をオンにすると、iPhone・iPadではドラムロール、Macでは時刻入力欄で時・分を指定できます。オフのままなら時刻なしで保存できます。
- Macのショートカットは`⌘N`（追加）、`⌘S`（保存）、`⇧⌘E`（画像出力）、`⇧⌘T`（今日）です。
- プランの操作メニューの「外観」からシステム設定に従う・ライト・ダークを選べます。選択は端末に保存され、書き出し画像の配色には影響しません。

## Markdown

```markdown
# 2026-11-26

## Morning
- [ ] 07:00 Morning routine
	Start your day

## Work
- [x] 09:00 Review pull requests
- [ ] 10:00 Team meeting
- Read a book
```

- `#`は日付またはタイトル、`##`はセクションです。日付はISO形式、英語の月名形式、日本語の年月日に対応します。日付のないタイトルは選択した日付を使用します。
- 見出しがないプランを開くと、Markdownの先頭にその日の `# YYYY-MM-DD` を補います。既存のタイトルや本文はそのままで、開いただけでは保存されません。
- iPhoneのMarkdown編集では、キーボード上のバーから `#`、`##`、`` ` ``、`` ``` ``、`*` を入力できます。`` ``` `` ボタンはバッククォート3文字だけを挿入します。
- バーの「…」から、今日または開いているプランの日付（`YYYY-MM-DD`）、タスクのチェック欄（`- [ ] `）、タスクメモ（`@note `）、その他の記号（`-`、`>`、`_`、`~~`、`[]()`）を挿入できます。
- キーボード上のチェックリストボタンで、カーソルのある行や選択した行をチェックリストに変換できます。空行ではチェック欄を挿入します。
- プランの操作メニューの「新規プランのテンプレート」から「日付のみ」「朝・昼・夜」「仕事の優先事項」を選べます。次に開く未作成の日から適用され、保存済みのプランは変わりません。
- `- [ ]`、`- [x]`、`- [X]`と通常の`-` / `*` / `+`リストに対応します。通常リストを完了にするとチェックリストへ変換します。
- タスク先頭の`HH:mm`を時刻として解釈します。範囲外の時刻はタスク名の一部として残します。
- タスク直後の2文字以上インデントされた行は説明文です。コードフェンス内のリストはタスクにしません。
- Dayframe独自の `@note メモ本文` をタスクの直後に書くと、インデントなしでもそのタスクの説明文にできます。
- 対応しない記法や自由記述も原文として保持します。完全なMarkdownレンダラーではなく、デイリープラン用の行指向パーサーです。
- 編集するとプレビューを即時更新し、350msの入力停止後に保存します。完了操作、日付移動、バックグラウンド移行でも保存します。
- 見出しの日付を変えると保存先の日付も変わります。その日付に既存プランがある場合は上書きせずエラーを表示し、入力中の原文を残します。

## 画像共有

共有ボタンからMinimal / Editorial / Dark / Paper / Oceanを選び、背景色・文字色・フォント・セクション・完了タスク・完了数・日付形式・署名を調整できます。本文にはヒラギノ明朝・ヒラギノ角ゴ・等幅のフォントを選べます。画像テンプレートの選択は次回も使われます。タスクやコードの文字サイズは75〜175%、日付見出しは75〜150%で個別に調整できます。
コードフェンスとその中身、単独行のバッククォート表記は画像にも原文のまま表示されます。Markdownファイルの書き出しでは原文全体を保持します。

画像書き出し画面の「アスペクト比」で、9:16（1080×1920px、初期値）、16:9（1920×1080px）、16:10（1920×1200px）、4:5（1080×1350px）を選べます。プレビューとPNGは同じ比率になり、文字の折り返しとページ分割も画像の寸法に合わせて変わります。日付見出しの区切り線は、文字サイズや折り返しに合わせて見出しのすぐ下に配置されます。長い一覧や長文は複数ページへ分割し、タスク本文を省略しません。ページ選択で確認し、保存ボタンで選択ページを保存、標準共有シートで全ページをまとめて共有できます。Instagramが共有先に表示されるかはインストール済みアプリ側に依存します。直接投稿は実装していません。

## データの保存

プランは端末内に保存します。別の端末に移すには、Markdownを書き出して移行先で読み込みます。ストアを開けない場合は削除・初期化せず、エラーを表示します。

## アーキテクチャ

- `DayframeCore`: UIに依存しないパーサー・行単位編集・IDの照合、SwiftDataのDayモデル、保存・復旧。
- `DayframeExport`: フォント計測を利用したページ分割、固定サイズのキャンバス、ImageRendererとImageIOによるPNG生成。通常の画面とは独立しています。
- `DayframeApp`: 日付ごとの編集セッション、ネイティブな画面とファイル入出力。選択日付はウィンドウ単位です。

DayのMarkdownを正とし、TaskとSectionは派生値です。IDのスナップショットだけをDay内へ保存し、原文と同じSwiftDataトランザクションで更新します。

日付はGregorianの`yyyy-MM-dd`キーとUTCの保存値で管理し、画面では端末のタイムゾーンへ復元します。端末のタイムゾーン変更でプランの日付が前日にずれません。

既存のストアに同じ日のDayが複数ある場合は、内容のあるDayを優先し、更新時刻とIDで一意に選択します。異なる原文は復旧用のMarkdownへ退避してから重複を整理します。入力中に別のウィンドウで同じプランが編集された場合と、Markdownインポート前も退避します。「復旧用の下書き」から復元・共有できます。退避に失敗した場合は削除しません。

署名済みMac版の保存先はアプリのSandbox内の`Library/Application Support/Dayframe`です。署名なしのXcodeテスト版は別の保存領域になる場合があります。開発中にBundle IdentifierやSandbox設定を変える前にMarkdownをエクスポートしてください。

## 検証

```sh
make test
make lint
make complex
make build
xcodebuild -project Dayframe.xcodeproj -scheme Dayframe \
	-destination 'platform=iOS Simulator,name=iPhone 18 Pro' test
xcodebuild -project Dayframe.xcodeproj -scheme Dayframe \
	-destination 'platform=macOS' test \
	CODE_SIGN_IDENTITY=- CODE_SIGNING_ALLOWED=YES CODE_SIGNING_REQUIRED=NO
```

Swift Testingで原文保持、ID保持、CRUD、日付変更、タイムゾーン、永続化の再読み込み、同日重複の退避、画像ページ分割とPNG寸法を検証します。XCUITestでタスク作成・完了反映・画像プレビュー、日本語の最大Dynamic Typeを検証します。UIテストは専用の一時ストアを使い、通常のデータには触れません。

フォント・色・操作ラベルはDynamic Type、VoiceOver、ダークモードに対応します。画像出力だけは固定サイズの作品として文字サイズを固定しています。Grid / Timelineテンプレート、カレンダー連携、AI生成、SNS直接投稿はMVPには含みません。

この環境ではMac、iPhone 18 Pro、iPhone Duoの主要操作と、iPhoneの日本語・最大Dynamic Typeを検証済みです。iPhone Duoの折り角変更・全回転・左右のSplit View、実機VoiceOverは手動確認が必要です。MacのUIテストはローカル署名が必要で、ウィンドウ復元がない場合は標準の新規ウィンドウ操作を行います。
